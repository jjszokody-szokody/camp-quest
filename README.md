# Camp Quest: Four Realms
Survival camp-building game for phone and computer (three.js PWA). All characters, animals, bosses, textures and animation are original procedural code.
Play: https://jjszokody-szokody.github.io/camp-quest/

## Release 3 — crafting, villages, graphics
- Grid crafting (2×2 bag / 3×3 bench, shaped + shapeless), recipe book auto-fill, slot inventory with drag & drop, bench tiers 1–4, item tiers wood→stone→iron→gold→obsidian→boss gear.
- Fuelled central campfire whose light radius keeps monsters away.
- Villages with houses, shops, wells, gardens, lamps; 20 named villagers with schedules, branching dialogue, side quests, rumors, coin shops, heart pieces.
- Graphics setting Low / Medium / High (auto Low on phones): PBR textures, sky + environment lighting, soft shadows, ACES tone mapping, reflective water, swaying grass, leaf-card trees, bloom + color grading, fire/smoke particles.
